# LIBERO behavior-cloning stack — full install for the `libero-modern` env
# (Python 3.10.20). Install into that env:
#     conda activate libero-modern
#     pip install -r requirements.txt
#     pip install -e ~/pythonprojects/LIBERO      # LIBERO itself (install_requires is empty)
#
# Two deliberate deviations from LIBERO's stock requirements.txt, both forced by
# hardware/runtime, both noted at their line:
#   1. torch/torchvision come from the CUDA 12.8 index (RTX 5090 = sm_120,
#      Blackwell). LIBERO ships no torch pin; the default index has no sm_120
#      build. This is the whole reason we left Python 3.8.
#   2. numpy pinned to 1.23.5 (LIBERO stock is 1.22.4). Anything >=1.24 removes
#      np.bool, which robomimic 0.2.0 still calls -> hard crash. 1.23.x is the
#      last line that keeps np.bool AND has cp310 wheels.

# ---- PyTorch (Blackwell / sm_120) --------------------------------------------
